## Systems and teams

At **[LicenseMarket](https://saeedghofrani.github.io/case-studies/license-market-backend-architecture)**, I work on CRM services, financial workflows, database performance, and production operations. I began managing engineers in early 2024; my responsibilities include hiring, one-to-ones, reviews, mentoring, and delivery planning.

Using GitHub Projects, issues, code reviews, and CI/CD helped the team miss fewer tasks, finish features more consistently, and release with fewer bugs. Our database and API timing work recorded a **40% reduction in average API latency**; availability was **99.9% over approximately six months**, tracked through UptimeRobot and incident records.
